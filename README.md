# Bokeh Web

Adapted from **Blurry** by Domenico Bruzzese, revision `10652e8495b498dedd83b88ac8e93253de7603e2`, under the [MIT License](./UPSTREAM_LICENSE).

- Original source: https://github.com/Domenicobrz/Blurry
- Codrops tutorial: https://tympanus.net/codrops/2019/10/01/simulating-depth-of-field-with-particles-using-the-blurry-library/

The original v5 Codrops article scene, accumulation shaders, camera, bokeh texture, and orbit controls are retained. The AlterU layer adds tap-to-start lifecycle control, mobile sampling tiers, three-plane focus calibration, bilingual UI, and publishing metadata.

Use `?baseline=1` to run the restored visual without the product HUD and focus loop.
